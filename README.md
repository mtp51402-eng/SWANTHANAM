# സാന്ത്വനം — പാലത്തുങ്കര (ഉപകരണ വായ്പാ കേന്ദ്രം)

Offline-first PWA. ഉപകരണങ്ങൾ, നൽകൽ/തിരിച്ചെടുക്കൽ, പൊതു അപേക്ഷ, WhatsApp ഉണർത്തൽ + മറുപടി ലിങ്ക്, അറിയിപ്പുകൾ, സ്റ്റോക്ക് PDF.

## Deploy
1. Firebase → Realtime Database (Singapore) ഉണ്ടാക്കുക (test mode / open rules).
2. `app.js` ലെ `CFG.DB` ൽ DB URL നൽകുക (അല്ലെങ്കിൽ ആപ്പിൽ: അഡ്മിൻ → ഓൺലൈൻ സിങ്ക്).
3. എല്ലാ ഫയലുകളും Firebase Hosting / GitHub Pages ൽ അപ്‌ലോഡ് ചെയ്യുക.
4. അഡ്മിൻ പിൻ **1234** — ഉടൻ മാറ്റുക.
